怎麼跟他玩

  • 摸頭療癒表情，30 秒後會睡著
  • 抓起 / 搖晃暈眩、昏倒、哭哭，隨機一種
  • 點嘴巴吃棒棒糖、漢堡或壽司
  • 點身體驚嚇，點滿十次會生氣氣
  • 點畫面好奇地看向你點的地方
  • 連點額頭兩下驚喜、開心
  • 拉臉 / 抓起啵啵：輕拉會變長、放開彈回；拉很遠就被抓起來，放手會掉下去、彈一下，再隨機反應。機器人直接抓起。按住啵啵會被壓扁
  • 戳臉頰 / 戳眼睛啵啵：臉頰會害羞、咯咯笑；戳眼睛會喊痛
  • 自己會動會打哈欠、哼歌、打噴嚏、打嗝、發呆，太久沒理他會睡著；被放到別處，過一陣子會自己走回來
  • 換角色設定裡可切換機器人／啵啵
